# 分析与报告标准

## 1. 代表样本选择

先去重，再排序。优先级如下：

1. 表格按多本书记录且有销量/订单/销售额：每本书先取销量最高的若干条，默认 3 条；再按整体销售表现补足 30 条。
2. 只有单本书的销售数据：按销量优先、销售额次之、互动表现再次排序。
3. 只有账号视频数据：按点赞量排序，并用评论、收藏、转发识别“讨论型”“收藏型”“传播型”内容。

保留未入选视频的汇总统计和主题分布，但不逐条重复分析。任何指标缺失都写明，不做零值推断。

## 2. 下载、转写与校正

- 按代表清单下载原视频，文件名使用稳定视频 ID。
- 使用 video-copy-analyzer 的“视频下载 + FunASR 字幕提取”流程，必须保留句段级时间戳。
- 校正仅限人名、书名、专名、同音字、明显断句和标点；不润色说法，不改变观点。
- 为每条视频保存原始转写与校正版。后续分析、脚本和剪辑只引用校正版，但可追溯到原始结果。
- 转写置信不足、背景音乐遮盖或多人重叠发言时，将相关片段排除出金句与自动粗剪，除非人工听校完成。

## 3. 唯一证据表

证据表每行对应一个可剪句段，至少包含：

| 字段 | 含义 |
| --- | --- |
| 视频 ID | 稳定去重键 |
| 书名/商品 | 无则留空 |
| 逐字文案 | 校正后的原话 |
| 源起止时间 | HH:MM:SS.mmm |
| 视频链接 | 可直接打开的原链接 |
| 本地素材 | 已下载视频路径 |
| 销量/互动 | 表格中的原始指标 |
| 主题标签 | 1–3 个中文标签 |
| 转写状态 | 已校正/需人工听校/不可用 |

报告、金句、脚本和剪辑清单都从这张表派生，不另建互相冲突的时间码。

## 4. 金句 Top 5/10

执行顺序：

1. 从全部可用逐字稿抽取观点完整、脱离上下文仍可理解的句子。
2. 将近义表达聚为同一“金句主题”，保留最适合剪辑的原话作为代表句。
3. 统计覆盖视频数优先，出现总次数次之；同一视频内的机械重复只计一次覆盖。
4. 若实际重复不足 5 条，宁可输出更少并说明，不虚构 Top 10。

每条必须列出：

- 排名与金句主题
- 代表原话
- 覆盖视频数/出现次数
- 每个证据的源时间码与视频链接
- 可复用原因：情绪、冲突、身份代入或行动指向

## 5. 报告建议结构

1. 数据范围与方法：表格范围、成功下载/转写数量、筛选规则、缺失数据。
2. 结论摘要：3–5 条真正影响选题和剪辑的结论。
3. 爆款主题地图：主题、受众情绪、代表数据、适合的平台场景。
4. 高互动/高转化视频深析：开场抓力 → 观点展开 → 情绪推进 → 信任建立 → 转化动作。
5. 金句 Top 5/10：使用上述证据格式。
6. 可复用结构：只总结素材中反复验证的结构，不自创新文案。
7. 其余视频合并观察：低频主题、长尾结构、失效模式。
8. 后续脚本建议：说明可组合的片段簇及风险，不重复粘贴整份逐字稿。

## 6. 写作约束

- “高转化”必须有销售指标，“爆款”必须说明使用的阈值。
- 区分相关性与因果性，例如写“与高销量同时出现”，不写“必然带来销量”。
- 不用 Hook、Emotion、CTA、B-roll 等英文概念；对应写“开场抓力、情绪推进、转化动作、辅助画面”。
- 每个具体判断紧邻证据，不把所有链接堆到文末。
- 报告完成后用 documents 渲染检查，避免表格截断、链接不可读和跨页孤行。
